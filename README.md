<h1 align="center">Walpaca</h1>

<p align="center">
  Web version of the native GTK AI client: <a href="https://github.com/Jeffser/Alpaca">Jeffser/Alpaca</a>
</p>

---

Walpaca is inspired by [Jeffser/Alpaca](https://github.com/Jeffser/Alpaca). After using the native GTK version daily, switching between a desktop and a laptop meant manually syncing the local `.db` file between machines. 

The question arose: *What if Alpaca had a web interface accessible anywhere on the local network or VPN?* Walpaca is the answer.

Instead of creating a new database format, Walpaca mounts the exact same SQLite database file (`alpaca.db`) used by the GTK app, wrapping it with a lightweight backend API and a modern web frontend. Your existing chats, configurations, and models remain fully compatible.

## Features

- [x] Talk to multiple models in the same conversation
- [x] Multi-instance support (connect multiple Ollama nodes across LAN or VPN)
- [x] Delete and edit messages
- [x] Regenerate messages
- [x] Pull and delete models directly from the UI with real-time progress
- [x] Model Context Protocol (MCP) tool integration (SSE/HTTP transports with multi-turn tool calling)
- [x] Bundled MCP servers for web page fetching (`fetch`) and web search (`web-search`)
- [x] Image and audio recognition (multimodal models) with clipboard paste & drag-and-drop
- [x] Document recognition (plain text & code files) with configurable context attachment scope
- [x] Code syntax highlighting
- [x] Multiple concurrent conversations
- [x] LLM Response background handler when browser is refreshed or closed
- [x] System notifications
- [x] Import chats
- [x] Export chats
- [x] Fork chats
- [x] PIN security lock with auto-lock timer & rate limiting
- [x] Custom prompts manager & quick-insert modal in chat
- [x] Lorebooks & Personas with automatic system prompt injection
- [x] In-chat match search and sidebar conversation search
- [x] Text-to-speech integration via Kokoro TTS with OS media controls
- [x] Speech-to-text integration via Whisper (live microphone recording & audio file upload)
- [x] 1on1 real-time voice conversation mode (VAD silence detection, auto-STT, streaming TTS & pitch-preserving speed control)
- [x] Configurable TTS and STT server URLs and API keys in Preferences
- [x] Mobile and tablet responsive design with drawer navigation
- [ ] YouTube video recognition (transcript queries)
- [ ] Website recognition (web scraping via URL)
- [ ] Connect to cloud-hosted OpenAI-compatible APIs using personal API keys

## Tech Stack

- **Frontend**: Next.js (App Router), React, Tailwind CSS, Zustand
- **Backend**: Python, Flask, Flask-SQLAlchemy, Flask-CORS, official `ollama` SDK, `mcp` SDK
- **Database**: SQLite (`alpaca.db` shared with GTK Alpaca)
- **Speech Synthesis**: Kokoro TTS Server
- **Speech Recognition**: Whisper STT Server
- **Extensibility**: Model Context Protocol (MCP) client
- **Orchestration**: Docker & Docker Compose

## Quick Start

### Prerequisites

- [Docker](https://docs.docker.com/get-docker/) & [Docker Compose](https://docs.docker.com/compose/)
- An existing `alpaca.db` file (from GTK Alpaca or generated on first run)
- Running [Ollama](https://ollama.com/) instance accessible from your host/network

### Running with Docker Compose

1. Clone the repository:
   ```bash
   git clone https://github.com/c42759/walpaca.git
   cd walpaca
   ```

2. Configure environment variables in `.env`:
   ```bash
   cp .env.sample .env
   ```
   Adjust `.env` as needed:
   ```bash
   COMPOSE_PROJECT_NAME=walpaca
   COMPOSE_FILE=docker-compose.yml
   NETWORK_ADDRESS=127.0.0.1
   VPN_ADDRESS=127.0.0.1
   CORS_DOMAINS="http://localhost:3100"
   KOKORO_API_KEY=your-kokoro-key-here
   WHISPER_API_KEY=your-whisper-key-here
   ```

3. Ensure `alpaca.db` and required directories are present in the project root:
   ```bash
   touch alpaca.db
   mkdir -p personas lorebook prompts config
   ```

4. Launch services:
   ```bash
   docker compose up -d
   ```
   *(Optional: Use `docker compose -f docker-compose-local.yml up -d` for `127.0.0.1`-only binding without Whisper, or run `docker compose -f mcp/docker-compose.yml up -d` to start the bundled `fetch` and `web-search` MCP servers on ports `8081` and `8082`.)*

5. Access the web interface at `http://localhost:3100` (Backend API on `http://localhost:5100`, Whisper STT on `http://localhost:9000`).
